# VisiBooks Homebrew Tap

Official Homebrew tap for [VisiBooks](https://visibooks.app), the native accounting workbench.

## Install

```sh
brew install visibooks/tap/visibooks
```

Or tap first, then install:

```sh
brew tap visibooks/tap
brew install --cask visibooks
```

## Upgrade

```sh
brew upgrade --cask visibooks
```

Release downloads are published at [visibooks/visibooks-releases](https://github.com/visibooks/visibooks-releases/releases).
